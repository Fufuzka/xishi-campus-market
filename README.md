# 夕拾 · 校园二手交易集市

基于 **Python FastAPI + Vue 3 + SQLite** 的可运行课程设计项目。包含设计、实现、测试、审查、部署配置和主要功能截图。当前网页测试版本 0.2.0-beta.1，日期 2026-10-19；包含新的搜索接口和筛选参数。

源码、设计文档和测试材料通过 Git 管理；用户数据库、上传图片、日志、环境和构建产物不入库。所有迭代均为测试版；如需使用 GitHub Release，必须标记为 Pre-release，不上传桌面安装包。日常提交、自动测试与发布说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 校园功能调整

按校园交易场景加入：学生姓名＋学号＋学院人工认证、商品发布和修改后的审核、校区与交易方式、商品删除、求购发布与联系、双方私聊、线下面交订单、管理员审核与举报处理、用户停用／恢复、分类管理及操作留痕。所有功能通过浏览器使用，支持手机 H5。设计、权限、表结构、接口和流程见 [13-校园交易与平台管理](docs/13-校园交易与平台管理.md)。

注册默认普通学生；认证通过后才能发布、私聊和发起交易。新商品待审，编辑重新待审。旧账号和商品保留，需补做认证与商品审核。人工审核不代表已接入学校学籍系统。可选 AI 审核尚未加入。

创建管理员（请先激活项目 Python 环境）：

```powershell
python -m backend.create_admin 管理员用户名
```

密码交互输入，不自带默认管理员，不覆盖已有学生账号。登录后侧栏显示“平台管理”。公网部署时不导入演示账号。

## 多图、消息与外观设置

商品和学生认证均可提交 1–3 张图片，管理后台点击缩略图可放大、切换及使用方向键查看；认证证明仅本人及管理员可访问。私信与交易约定合并为“消息与交易”，在同一对话中聊天、约面交和确认完成，历史约定可回看。

右上角“外观设置”可在林间集市、轻简横栏、清单浏览之间即时切换，并在当前浏览器记住选择。“工作空间”文字已移除。详见 [14-多图审核与消息布局](docs/14-多图审核与消息布局.md)。

## 搜索与筛选

点击搜索框可查看历史和可能想搜，输入时显示来自在售商品的联想。默认最相关；价格按钮在低到高 / 高到低间切换。筛选面板支持分类、价格、成色、1 / 3 / 7 / 14 天内发布，已选条件可逐个移除。历史记录按账号或设备隔离，最多 12 条。详见 [12-搜索发现与筛选设计](docs/12-搜索发现与筛选设计.md)。

## 本机网页测试服务

当前工作区也可双击 `启动网页测试.cmd`，再在浏览器打开 http://127.0.0.1:8007。脚本使用隔离演示目录 `test-data/campus-preview`，不会自动创建管理员。测试期间保留启动窗口；关闭窗口或按 Ctrl+C 会停止服务，已打开的浏览器仍可能保留页面，但无法提交登录等请求。需要恢复时重新运行脚本。

登录或注册弹窗关闭后清空用户名、密码、昵称并返回登录模式；密码恢复隐藏。网络请求失败显示中文连接提示，15 秒无响应提示超时，可以重试。`scripts/auth-browser-test.cjs` 验证该行为。

## 本机启动

需要 Python 3.12。Vue 已随项目保存，无需 Node、前端构建或在线 CDN。

Windows PowerShell：

```powershell
cd D:\wuwu\campus-market
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Demo
```

Linux / macOS：

```sh
sh start.sh --demo
```

打开 http://127.0.0.1:8000 ，接口文档 http://127.0.0.1:8000/docs 。`-Demo` / `--demo` 显式添加示例商品；已有用户时不会再次写入。

演示账号：`demo`（夕拾同学）、`buyer`（小林同学），密码均为 `Campus2026!`。只用于本地演示。普通用户可自行注册，生产环境不要导入演示账号。

当前工作环境的运行使用上一级目录的 `.venv`；交付脚本会在项目自身创建独立环境，因此复制项目后仍可运行。

## 功能

商品发布支持标题、描述、价格、图片上传或 HTTPS 图片 URL、分类、成色、地点和联系方式。集市提供列表、详情、关键词搜索、分类、价格区间、排序和分页。个人空间支持编辑、上下架、售出标记、查看留言。还实现了收藏、取消收藏、买家留言和卖家回复。

普通注册登录用于课程业务演示，支持管理员人工审核姓名、学号及学院，尚未接入校园统一身份系统。提供线下交易订单跟踪，不含在线支付、物流或线上结算。

## 复现测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q --junitxml=evidence/test-results.xml
```

浏览器验收脚本 `scripts/browser-test.cjs` 需要 Node、Playwright 和已安装 Edge；先启动隔离演示服务、创建测试管理员并设置 `BASE_URL`、`TEST_ADMIN_USERNAME`、`TEST_ADMIN_PASSWORD`，再执行 `node scripts/browser-test.cjs`、`node scripts/search-browser-test.cjs`、`node scripts/campus-browser-test.cjs`。脚本会创建一个独立验收账号和商品，并留下带“自动化验收”字样的留言；应仅在本地验收数据库执行。
