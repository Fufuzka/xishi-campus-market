# 网页界面与密码可见性

> 本次校园功能增量以 [13-校园交易与平台管理](13-校园交易与平台管理.md) 为准：新增学生人工认证、商品审核、求购、私聊、线下订单和管理后台；旧功能规格及测试数字为历史记录。

版本 0.2.0-beta.1（测试版） · 日期 2026-10-19

夕拾保留固定侧栏、顶部工具栏、商品工作区和手机响应式布局，作为浏览器内的网页界面。页面移除连接设置、本地 / 联网状态和桌面桥接调用；帮助只介绍业务流程，侧栏和浏览器标题明确显示测试版。

登录和注册提供密码眼睛按钮。默认隐藏，点击显示 / 隐藏不修改内容；关闭弹窗、登录成功、切换登录 / 注册时复位。按钮使用 type=button、aria-label 和 aria-pressed，支持键盘操作。

历史桌面样式改版的业务交互予以保留，桌面运行方式已撤下。当前以浏览器验收为准；证据见 evidence/browser-results.json、search-browser-results.json 和 web-api-tests.xml。公网部署及导师评审仍待完成。

## 登录弹窗清理

关闭按钮、Esc 或点击遮罩均清空账号、密码及昵称，退出注册后重置为登录模式，密码恢复隐藏。网络错误改为中文提示并提供重试；请求等待最多 15 秒。依据用户反馈恢复已停止的本机预览服务，测试时使用项目根目录的启动网页测试.cmd 保持服务运行。6 项针对性浏览器检查通过，证据见 evidence/auth-browser-results.json。
