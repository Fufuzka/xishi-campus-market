# 桌面界面改版与密码可见性

版本 1.2.0 · 日期 2026-10-18

## 1. 用户需求与改动

用户要求输入密码时能检查是否输错，同时希望软件具有清晰的桌面应用样式。本版保留商品业务和既有本地数据目录，重新组织主界面，增加密码查看控件。

| 改动 | 行为 |
|---|---|
| 密码眼睛按钮 | 登录和注册均支持，点击在隐藏 / 显示间切换，不修改已输入内容 |
| 默认隐藏及复位 | 初始隐藏；关闭弹窗、登录成功、登录 / 注册切换时恢复隐藏 |
| 固定左侧栏 | 逛集市、我的收藏、我的发布始终可见，当前页面突出显示 |
| 顶部工具栏 | 显示当前位置，提供刷新、账号及发布入口 |
| 集中工作区 | 缩小宣传内容，优先显示搜索、筛选和商品卡片；按窗口宽度排三或四列 |
| 侧栏连接入口 | 桌面版直接打开独立原生设置窗口，保留原生菜单备用入口 |
| 模式状态卡片 | 根据桌面启动参数显示本地演示或联网使用；普通浏览器明确显示浏览器访问 |
| 使用帮助 | 说明浏览、登录收藏、管理发布等主要流程 |
| Windows 文件信息 | EXE 产品名夕拾，文件版本及产品版本 1.2.0 |

## 2. 密码交互约束

按钮为 type=button，不触发表单提交；使用 aria-label“显示密码”或“隐藏密码”和 aria-pressed 表达状态。密码通过同一 input 的 type 在 password / text 间切换，保留绑定值与自动填充属性。眼睛按钮可通过键盘聚焦和触发。截图中的 ExampleOnly8! 是专用于验收的示例文本，不是真实用户密码。

## 3. 桌面连接边界

桌面主窗口仅暴露 `show_settings`，用于打开本地设置窗口；不会在商品窗口暴露配置读写、任意文件操作或系统命令。保存连接设置、测试服务器、读取配置仍只存在于独立本地设置窗口。普通浏览器访问的侧栏入口显示说明，不冒充已安装桌面程序。

桌面启动携带 desktop / mode 页面参数供展示，真实服务连接与配置由桌面控制器决定；页面参数不用于认证、所有权或其他安全判断。

## 4. 版本验证

原接口与桌面配置自动化 41 项通过。浏览器流程共 13 项通过，新增密码显示隐藏、重开复位及注册切换检查，以及侧栏、帮助、连接说明入口检查；原商品发布上传、编辑、上下架、收藏、询价、卖家回复与手机宽度检查继续通过。证据为 `evidence/browser-results.json`、`desktop-and-api-tests.xml`。

`09-password-visibility.png` 展示眼睛按钮及可见状态，`01-home.png` 展示新版侧栏与工具栏，实际 EXE 窗口已目视验证，`desktop-settings.png` 展示连接设置。EXE 自检覆盖资源、演示数据、商品及会话重启持久化。公网部署状态不因界面改版改变，仍待真实服务器验收。

## 5. 升级使用

关闭旧软件后，解压新版并运行夕拾.exe。默认业务数据目录保持 `%LOCALAPPDATA%\ShiguangMarket`，不会因 1.2.0 改版清空已有商品、账号或图片。连接同一服务器时，服务器也需部署新版前端，客户端加载的是服务器当前提供的界面。
