# 折叠导航、筛选定位与密码找回

网页测试版 0.2.0-beta.1 · 2026-10-24 · 开发自审，待导师评审

本增量取代 14、16 文档中的消息内嵌订单方案；历史设计与截图保留为过程记录，当前行为以本章为准。

## 1. 功能规格

- 侧栏主入口保留集市、求购、消息、我的交易、收藏、账户设置及管理员的平台管理。我的交易可展开／收起，包含我的发布、我卖出的、我买到的。账户设置包含个人资料、账号与安全、学生认证、我的举报。进入子页面自动展开对应分组；折叠按钮具备 aria-expanded 和关联区域。
- 筛选抽屉左侧按钮滚动右侧独立内容区，定位到对应标题上方 20px。动态增加末尾留白，使最底部的发布时间也能顶到目标位置，不滚动整个网页。
- 登录／注册／找回弹窗点击遮罩、按 Esc 均不关闭，只通过右上角 × 主动关闭；登录成功正常结束弹窗。关闭后清空密码、昵称、找回答案等草稿并恢复隐藏状态。
- 消息页只处理沟通：展示联系人、商品咨询／求购联系／直接私信来源、来源标题、最近内容和时间；支持按来源及联系人／内容搜索。可以查看来源商品、转到求购、与该联系人单独私信，或跳到相关交易记录。新回复优先排序。
- 面交安排、取消、双方完成确认放入买入／卖出中心。发起约定后进入“我买到的”；继续沟通进入消息页。取消后重新约定保留两条交易历史，不在消息中渲染交易操作卡。
- 直接私信不绑定商品或求购，只能由已通过学生认证的用户发起；双向重复发起复用同一个会话，消息仍受参与者隔离与停用校验保护。UI 从已有联系人发起，不公开所有用户清单。

## 2. 三个安全问题与找回流程

系统提供固定三个问题，至少设置一个、最多三个。保存时验证当前密码；每次保存替换整组配置，界面明确提示填写所有希望保留的答案。设置状态可以查看，原答案永不回显。答案要求 2–128 字符，先按 NFKC、忽略大小写和首尾／重复空格归一化，再使用与密码相同的带独立随机盐 PBKDF2 摘要保存。

登录框提供“忘记密码？”入口。填写用户名、曾设置的问题答案和两遍新密码；未设置的问题留空，所有已设置问题必须回答正确。客户端核对两遍新密码，服务端独立校验 8–128 字长度与全部配置答案。重置成功撤销该账号全部会话，不自动登录，返回普通登录表单。

未设置问题的旧账号无法凭空找回，需要先登录到账户设置中配置；不为旧账号生成默认答案。账号不存在、未设置、答案错误、停用均使用相同失败说明，公共端始终返回相同三个问题，不提供账号存在性或已配置题号查询。每次校验均执行三次摘要核验，不告诉用户是哪题错误。

找回提交按账号最多 5 次／15 分钟、请求 IP 最多 20 次／15 分钟限制；限制记录在数据库中，失败不因事务回滚清除。限制只影响找回，不锁定正常登录。答案不进入响应、日志、浏览器本地存储或交付数据；未添加短信、邮箱或第三方身份验证。

参考 [OWASP Forgot Password Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html) 的一致错误说明、限制自动尝试、重置后撤销会话和重新登录要求。OWASP 不建议将安全问题作为唯一正式恢复凭据；此处按课程测试版要求实现，尚不能作为生产级强身份恢复方案。

## 3. 表结构与架构增量

| 数据 | 内容 |
|---|---|
| security_questions | user_id 外键、question_id（1–3）、answer_hash；用户／题号联合主键，随用户删除 |
| recovery_attempts | key（账号或 IP 的 SHA256 标识）、attempts、window_start；每次请求清理过期窗口 |
| conversations | 沿用 product_id、wanted_id；两者都为空表示直接私信。新增双向用户对唯一索引，避免重复直聊 |

新增 backend/recovery.py 独立注册恢复路由，复用密码摘要、会话、数据库和跨站提交校验。只补充迁移，不删除旧商品、订单、会话或认证材料。原会话由关联字段自动确定来源类型。

## 4. API

| 方法／路径 | 规则 |
|---|---|
| GET /api/auth/recovery-questions | 公共固定三个问题，与用户名无关 |
| GET /api/me/security-questions | 登录后返回问题目录和本人已配置题号，不含摘要和答案 |
| PUT /api/me/security-questions | current_password、answers[{question_id,answer}]；1–3 个不重复问题；旧密码错 400、无效字段 422 |
| POST /api/auth/recover | username、answers、new_password；失败统一 400、过频 429、成功撤销会话并返回 ok |
| POST /api/conversations | product_id／wanted_id／peer_id 恰选一个；直聊双方唯一；自己 422、无效或停用联系人 404 |
| GET /api/conversations | 增加 peer_id、source_type、last_message_at、last_message_id；只返回参与者会话，按最近消息排序 |

## 5. 自审与验收

新增 8 项接口测试涵盖问题数量／重复／空白、设置密码校验、摘要与不回显、替换配置、全部问题校验、会话撤销、统一失败、持久化限流及恢复、跨站请求、直聊双向复用、越权与来源排序。原浏览器用例同步调整为折叠导航、仅 × 关闭和独立交易中心的操作，保留发布、搜索、认证、权限、订单状态、多图和布局断言。新增浏览器专项验证准确定位、遮罩／Esc、分组开关、安全问题、找回、直接私信、来源筛选与桌面／手机布局。最终数量和原始证据见 06 文档。

自审已修复横栏展开分组宽度挤压导致按钮重叠，并在三种布局复验。只读数据库曾在本机验收时产生一次写入错误，确认文件可写并重跑对应浏览器流程通过；不将失败记录作为通过证据。公网升级仍需重新验证 HTTPS Cookie、持久化、代理客户端 IP 与管理员审核，未冒充导师评审或实际远程部署验收。
