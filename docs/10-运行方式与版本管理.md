# 运行方式与版本管理

## Web 运行方式

夕拾通过浏览器使用。FastAPI 同时提供 Vue 页面、静态资源和 JSON API；前端使用相对路径，不需要手动切换本地／联网模式。

本机默认访问 http://127.0.0.1:8000；CloudStudio 使用平台生成的 HTTPS 预览。启动参数见 README，持久化与服务器配置见 [部署与运维](08-部署与运维.md)。

## 数据目录

MARKET_DATA_DIR 包含 SQLite、商品上传和私有认证证明。开发、浏览器测试、模拟数据与实际站点使用不同目录。升级前备份数据，核对迁移兼容性；恢复时同时检查数据库与关联图片。

## 版本策略

当前为 0.2.0-beta.1。测试节点使用 beta 标识和 Pre-release。代码推送、测试通过与远程部署分别记录，不因部署到公网自动改变版本阶段。

## 历史版本

早期桌面实现保留在 Git 历史及历史 Pre-release 中，已停止维护。当前维护对象为 Web 应用；旧桌面数据不会自动导入站点，迁移需独立验证。
