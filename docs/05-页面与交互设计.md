# 页面与交互设计（可选原型交付）

文档编号 SGM-UI-001 · 版本 1.0 · 日期 2026-10-18

## 1. 视觉与页面结构

品牌“夕拾”，主题为校园物品循环利用。主色深绿，浅米绿底色，价格用暖棕色突出。商品图片为统一比例示意图，真实用户可上传实物照片。所有商品关键操作都可由可见按钮完成。

桌面结构：固定左侧导航（品牌、集市、收藏、发布、连接设置、帮助和模式状态）＋顶部工具栏（当前位置、刷新、账号和发布）＋商品工作区（精简横幅、搜索、筛选、三至四列商品卡片）。手机小于 760px 时侧栏收为顶部导航，商品两列，表单和详情改为单列。

```text
┌ 夕拾侧栏 ───────┬ 当前位置 ── 刷新 / 账号 / 发布 ┐
│ 逛集市         │ 校园集市 · 精简引导条           │
│ 我的收藏       │ 搜索输入 / 分类 / 价格 / 排序    │
│ 我的发布       ├ 商品卡片 ─ 商品卡片 ─ 商品卡片  ┤
│               │ 图片 / 成色 / 标题 / 金额       │
│ 连接设置       │ 卖家 / 面交地点 / 状态          │
│ 使用帮助       │                               │
│ 本地或联网状态 └ 分页 / 页脚                    ┘
└───────────────┘
```

## 2. 页面 / 弹窗清单

| 页面或弹窗 | 核心布局 | 主要交互 |
|---|---|---|
| 首页集市 | 横幅、筛选区、商品网格 | 点击分类即筛选；关键词回车；价格确认；重置 |
| 登录 / 注册 | 单列短表单 | 切换注册，眼睛按钮显示 / 隐藏密码，关闭或切换表单恢复隐藏，错误时保留内容 |
| 发布 / 编辑 | 桌面左图右表单，手机单列 | 上传预览、图片 URL、描述、价格、分类、地点、联系 |
| 商品详情 | 桌面左图右信息，下方留言 | 收藏、登录联系、询价、卖家回复 |
| 我的发布 | 状态统计、商品卡片、管理按钮 | 编辑、下架、上架、售出二次确认 |
| 我的收藏 | 收藏商品列表 | 查看详情、取消收藏、展示非在售状态 |
| 售出确认 | 说明和取消 / 确认 | 明确售出不能恢复在售 |

## 3. 反馈与可用性

请求进行中显示加载状态；保存、认证和收藏按钮处理中禁用。筛选无结果显示清除按钮，网络错误显示重新加载。输入具备 label 或 aria-label，错误消息通过提示条显示，键盘焦点可见；Escape 可关闭弹窗。未登录点击个人空间或发布会进入登录弹窗。

尚未实现完整的对话框焦点锁定、屏幕阅读器专项测试和跨浏览器兼容矩阵，不能将当前基础标签支持表述为完全无障碍合规。
