## 1. 审查性质与结论

本报告为本次交付过程中的 **AI 辅助自查记录**，审查对象为 Spec、架构、数据库、API、前后端代码和测试证据。并非独立第三方审查，不代表导师审批。可进入导师评审和本地演示；公网生产发布条件尚未全部满足。

## 2. 设计审查

| 编号 | 审查问题 | 结果与依据 |
|---|---|---|
| DR-01 | 是否覆盖题目三个必做功能 | 已覆盖：发布；列表详情和筛选；本人编辑、下架及查看留言 |
| DR-02 | 是否包含四类设计文档 | Spec、架构、数据库、API 均单独交付，OpenAPI 同步生成 |
| DR-03 | 金额和状态规则是否明确 | 整数分；sold 不可恢复；非在售停止新增留言 |
| DR-04 | 数据所有权是否在服务端校验 | owner_id 使用会话用户；编辑与状态变更调用 owned 检查 |
| DR-05 | 接口和数据库是否一致 | 商品字段对应 SQL，price ↔ price_cents 转换明确 |
| DR-06 | 原型是否可与实现对照 | 页面结构文档和 8 张运行截图配套 |
| DR-07 | 有没有未确认的需求 | 学校名称、是否必须学生身份认证、导师格式要求、远程服务器信息待确认 |

## 校园功能增量自查（2026-10-19）

认证资料仅本人和管理员访问；注册不接受角色；管理员显式创建，不提供默认生产密码；商品发布及编辑待审、隐藏内容的详情及留言返回 404；私信和订单校验参与者；唯一活动订单及状态更新使用数据库约束与事务；卖家不可通过编辑、删除或状态操作绕过进行中订单。举报下架或用户停用取消未结束订单；分类停用重启不恢复；旧数据迁移保留原值并设置待审。针对停用卖家直接以商品 ID 发起订单的绕过路径加入服务端拒绝及测试。

限制：人工审核没有接入学校官方系统，管理员应人工核验资料；公网部署前仍需完成原有身份、限流、备份、恢复和服务器 HTTPS 验收。AI 审核、在线付款均未实现。本记录为 AI 辅助自查，不是导师批准。
