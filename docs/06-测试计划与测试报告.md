文档编号 SGM-TEST-001 · 版本 1.0 · 执行日期 2026-10-18

## 1. 范围与方法

测试关注课程必做功能和三个选做功能，同时覆盖权限、状态、价格精度、数据隔离及图片有效性。采用两层验证：FastAPI TestClient 自动化接口测试；Edge 无头浏览器端到端操作与页面截图。人工检查桌面与手机截图布局。未进行压力测试、渗透测试或公网服务器验收。

## 2. 环境及隔离

Windows / Python 3.12 / FastAPI 0.115.12 / Vue 3.5.13。接口每项测试使用 pytest 临时独立数据库，不修改演示数据；浏览器使用真实本地服务 `127.0.0.1:8000`，创建专用验收账号。依赖完整快照见 lock 文件。

执行命令：`python -m pytest -q --junitxml=evidence/test-results.xml`。原始接口结果位于 `evidence/test-results.xml`；浏览器结果位于 `evidence/browser-results.json`，脚本位于 `scripts/browser-test.cjs`。
