# 功能规格说明书

版本：0.2.0-beta.1 · 更新：2026-10-25

## 产品范围

夕拾面向校园闲置物品的信息发布、沟通与线下面交。主要参与者为游客、学生和管理员，账号角色为 student / admin。平台不提供在线支付、资金担保或物流。

## 角色与权限

| 角色 | 能力 |
|---|---|
| 游客 | 浏览已审核的在售商品、搜索和筛选；联系方式需登录后查看 |
| 已登录学生 | 管理个人资料、收藏、留言、提交认证、查看本人记录 |
| 已认证学生 | 发布商品与求购、发起私信和线下订单 |
| 管理员 | 认证与商品审核、举报处理、用户状态、分类及操作记录 |

认证是人工资料审核，不能替代学校统一身份系统。商品、订单、会话和认证资料的权限均在服务端校验。

## 功能与验收规则

| 模块 | 要求 |
|---|---|
| 商品 | 标题、描述、价格、分类、成色、校区、交易方式、地点、联系方式及 1–3 张图片；新增和编辑后等待审核 |
| 搜索 | 标题和描述关键词、输入联想、历史搜索；分类与成色多选，结合价格／校区／发布时间筛选与分页 |
| 排序 | 默认相关度；价格升降、最新发布、卖家最近活跃与实验成交参考 |
| 降价 | 保存实际变价，展示前价与降幅；涨价撤销当前降价标记，修改仍需审核 |
| 个人管理 | 只管理本人商品；支持编辑、上下架、删除、售出标记；历史订单保留 |
| 求购 | 发布物品需求、预算、成色和校区，支持联系与结束求购 |
| 消息 | 商品咨询、求购联系、直接私信；仅参与者可读写；按来源和内容筛选 |
| 交易 | 买卖记录分开查看；卖家安排面交，双方确认后完成；进行中的商品不能编辑或删除 |
| 收藏和留言 | 收藏幂等，个人列表隔离；商品根留言与卖家回复，非在售商品停止新增留言 |
| 账号 | 昵称与公开简介、修改密码；三个安全问题至少配置一个，找回需核验全部已设置答案 |
| 管理 | 审核认证和商品，处理举报、停用用户、管理分类，保留操作记录 |
| 布局 | 三种外观、响应式页面、折叠导航、横栏纵向菜单；登录弹窗仅通过叉主动关闭 |

## 状态与数据约束

商品状态为 on_sale / off_shelf / sold；审核状态为 pending / approved / rejected。未审核或卖家停用的商品不进入公开搜索。已售商品不能重新上架，重新销售需新建记录。

订单状态为 pending_communication → pending_trade → completed；活动订单可以 cancelled。每个商品同时最多一条活动订单。买卖双方都确认完成后才将商品标记售出；取消释放预订，历史记录保留。

金额由 Decimal 校验，按整数分保存。事务和唯一索引用于保证状态与预订一致性。图片解码校验后重编码；认证证明与公开商品图片分别授权访问。

## 非功能边界

同源 API、HttpOnly Cookie、密码与安全答案摘要、请求来源校验、数据所有权检查。搜索历史按账号或设备隔离；布局偏好仅保存在当前浏览器。

当前面向单实例部署。未接入校园 SSO、在线支付、推送或第三方强身份恢复；尚未完成大规模负载及完整生产限流专项验证。详细技术边界见 [工程审查记录](07-工程审查记录.md)，测试执行范围见 [测试记录](06-测试计划与测试报告.md)。
