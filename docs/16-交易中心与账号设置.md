# 交易中心、账号设置与实验筛选

> 最新折叠导航、消息与交易分离、安全问题找回以 [17-折叠导航与密码找回](17-折叠导航与密码找回.md) 为准。

网页测试版 0.2.0-beta.1 · 增量日期 2026-10-24

## 1. 功能规格与验收规则

| 功能 | 规则 |
|---|---|
| 新降价 | 商品价格真实降低时记录前后金额与时间，列表显示上次价格及降幅；筛选仅保留当前价格低于上次价格的商品。再次涨价取消降价标记。修改仍需管理员重新审核。 |
| 快捷条件 | 集市提供新降价与直接输入价格区间；成色和发布时间统一在筛选面板操作，沿用标签删除和价格排序。 |
| 最近活跃 | 按卖家最近登录／已认证请求的时间排序，活动更新最多每分钟一次。自动刷新消息也可能更新活动；不表示人工正在回复。不收集定位。 |
| 成交参考（实验） | 按卖家双方确认完成的订单笔数排序，不计待交易、取消、单方确认或手工标记售出的商品。不等同信用评级，不生成好评率或担保承诺。 |
| 我买到的／我卖出的 | 只展示当前用户参与的订单，分待沟通、待交易、已完成、已取消；显示状态数量，继续沟通进入既有统一会话，支持取消进行中的约定。 |
| 个人资料 | 修改公开昵称（去空格后 1–24 字）和简介（最多 200 字）。用户名不可修改；不能修改角色、认证状态或实名信息。商品卖家处可查看公开简介。 |
| 账号与安全 | 校验当前密码，新密码 8–128 字且不能与旧密码相同。成功后撤销全部旧会话，给当前浏览器重新签发 Cookie；离开页面及成功提交清空密码并恢复隐藏。 |

不增加定位、支付、发货、退款、验货担保或商业卖家身份按钮。没有对应业务数据的功能不提供虚假入口。

## 2. 架构与数据库增量

沿用同源 FastAPI + Vue + SQLite。资料、改密和筛选使用现有权限依赖及跨站提交校验；买卖记录复用 `/api/orders` 的参与者隔离，不另造一套订单状态。

| 表 | 新字段／用途 |
|---|---|
| users | bio（公开简介）、last_active_at（UTC 活动时间）、is_demo（模拟记录标记），默认分别为空、空、0 |
| products | previous_price_cents（上次变价前的金额）、price_reduced_at（最近一次降价时间，涨价清空） |
| price_changes | id、product_id 外键、old_price_cents、new_price_cents、created_at；每次实际变价记录，不重复记录同价编辑 |
| orders | 新增 seller_id / status 索引；原表与状态不变 |

迁移幂等，旧账号、商品、订单保留，不根据旧数据编造历史活动或降价。公开商品仅增加卖家公开简介、活动时间、模拟标记及完成笔数，不返回学号、实名、证明图片或密码摘要。

## 3. API 设计

| 方法／路径 | 输入与结果 |
|---|---|
| GET /api/me/profile | 当前用户的 username、nickname、bio、created_at；需登录 |
| PATCH /api/me/profile | nickname、bio；只更新本人两项公开字段 |
| POST /api/me/password | current_password、new_password；错旧密码 400、字段或同密码 422、未登录 401；成功刷新当前会话 |
| GET /api/products | 新增 reduced=true，sort=recent_active／completed_sales；与原关键词、分类、校区、价格、成色、时间、分页组合 |
| GET /api/orders | 复用参与者权限；前端按 buyer_id／seller_id 和状态筛选 |

改密界面的 confirm_password 只用于前端一致性检查，服务端独立校验密码长度与原密码。密码不写日志或本地存储。接口继承 no-store、HttpOnly、SameSite 和 HTTPS Secure Cookie 配置。

## 4. 独立模拟数据

命令只接受空数据库，存在任何账号即拒绝导入。示例（CloudStudio 的 Python 路径以启动日志为准）：

```sh
export MARKET_DATA_DIR=/workspace/xishi-experiments
.venv-3.11/bin/python -m backend.seed_experiments
sh start.sh --cloud
```

导入 demo／buyer 两个模拟账号（密码 Campus2026!）、明确标注的模拟商品和简介、两组降价、不同活动时间、四种状态订单。模拟时间和成交不是真实行为；商品卡、标题和资料明确标注。导入后真正登录会更新该账号的活动时间。该命令不创建管理员，不覆盖正在使用的数据库。退出实验环境后应恢复原 MARKET_DATA_DIR。

## 5. 审查与测试记录

自审重点：变价与编辑在同一事务内；未审核商品不因降价筛选绕过可见性；涨价不残留优惠标记；改密校验当前摘要、轮换所有会话；活动信息不包含位置；模拟数据不注入已有账号；资料读取期间禁止提前编辑，避免异步返回覆盖输入。

新增 6 项接口测试覆盖资料所有权／空白与超长校验／权限字段不提升、密码错误／同值／长度／其他会话失效、降价审核／涨价／历史、模拟数据标记与拒绝覆盖、真实活动和成交排序、重复迁移。新增 10 项浏览器检查覆盖快捷筛选、排序、买卖与状态、进入会话、资料保存、密码清空和改密、三种布局在桌面／手机的页面适配。原功能另执行回归，最终结果见 06 文档和 evidence 中的原始证据。

本记录为开发自审。远程环境升级后仍需验证实际 HTTPS 登录、管理员审核和持久化目录。
