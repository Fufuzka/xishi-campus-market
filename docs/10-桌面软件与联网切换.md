# Windows 桌面软件与联网切换

文档编号 SGM-DESKTOP-001 · 桌面版本 1.2.0 · 日期 2026-10-18

## 1. 使用方式

解压 Windows 便携版，双击 `夕拾.exe`。软件自动打开独立窗口，启动本地服务并显示商品；不需安装 Python、Node，不需手动打开浏览器。首次创建本地数据库并导入 8 件演示商品，已有用户后不覆盖。演示账号 `demo` / `buyer`，密码均为 `Campus2026!`。

适用于 Windows 10 / 11 的 64 位系统，需要 Microsoft Edge WebView2 Runtime。本机 Windows 11 已完成真实 EXE 窗口验收，未在干净 Windows 10 虚拟机测试。目标电脑如缺少 WebView2，可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)安装 Evergreen Runtime 后重试。WebView2 不包含在 EXE 中。

这是便携版，不修改系统注册表，不自动创建桌面快捷方式。EXE 内含 Python、FastAPI、Vue、业务代码和演示素材。关闭软件自动停止其本地服务；商品和图片不会删除。

## 2. 本地数据位置

数据保存在 `%LOCALAPPDATA%\ShiguangMarket\data`，配置在同级 `config.json`，日志为 `desktop.log`，网页会话存储在 `webview`。真实业务数据不写入 EXE 临时解压目录，因此更新软件不会删除商品。共享电脑使用后应退出登录。

原浏览器项目的 `项目目录/data` 与桌面版数据目录独立，本版不自动迁移旧数据。需要迁移时应先停止两边服务、备份，再复制数据库及对应 uploads，不能在线复制未检查的 SQLite 文件。备份整个用户数据目录还会包含会话和联系方式，应限制访问。

## 3. 以后切换联网模式

先按 08 文档部署同一套 FastAPI + Vue 服务器，取得真实 HTTPS 地址，再执行：

1. 打开窗口顶部“夕拾 → 连接设置”。
2. 选择“联网使用”，填写服务器站点根地址，例如 `https://market.example.edu`。
3. 点击“测试连接”，成功后点击“保存并切换”。
4. 主窗口加载服务器站点，本地服务停止；使用服务器上的账号注册 / 登录。
5. 下次启动使用保存的模式；选择“本地演示”并保存即可恢复本地商品。

只填根地址，不加 `/api`、页面路径、查询参数或用户名密码。联网地址必须使用 HTTPS；仅 localhost / 127.0.0.1 / ::1 的本机测试允许 HTTP。不跳过证书检查，不自动跟随健康接口重定向。连接检查失败不会覆盖当前配置。

两种模式的数据、账号、商品、图片和留言各自独立。切换不是同步，不会自动上传本地数据。桌面连接能力不替代公网服务器部署，也不替代正式运行需要的审核、限流和校园身份认证。

## 4. 实现与安全边界

| 模块 | 责任 |
|---|---|
| desktop/config.py | 配置原子写入、URL 校验、服务器健康检查 |
| desktop/runtime.py | 仅绑定 127.0.0.1 的后台服务，随机端口、启动等待、退出停止 |
| desktop/main.py | 独立窗口、菜单、模式切换、同目录单实例、日志 |
| desktop/settings.html | 设置窗口、连接反馈、数据独立说明 |
| run_desktop.py | 源码与 EXE 共用启动入口 |
| scripts/build-desktop.ps1 | PyInstaller 单文件 EXE 构建 |

主商品窗口只暴露 show_settings，用于打开本地设置窗口；配置读写接口只提供给打包在本机的设置窗口，商品页不能调用原生文件或配置操作。服务器认证直接通过该服务器 Cookie，不经过本地转发代理。本地服务不对局域网开放，随机端口不能用作多人共享服务。

## 6. 重新构建

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe run_desktop.py
.\scripts\build-desktop.ps1 -Python '.\.venv\Scripts\python.exe'
```

输出为 `dist/夕拾.exe`，构建不包含开发数据库。`SHIGUANG_HOME` 仅供开发验收指定隔离数据目录，普通使用不需设置。

## 7. 常见问题

打不开：核对 64 位 Windows 与 WebView2 Runtime；失败弹窗给出日志路径。首次自解压可能稍慢。端口冲突：软件自动选取可用端口，无需固定占用 8000。联网服务器不可用：从原生菜单打开设置切回本地演示。

替换或移动 EXE 不会清除已保存数据。需要从零演示时应先备份，再使用独立测试目录；本版没有一键删除数据功能。
