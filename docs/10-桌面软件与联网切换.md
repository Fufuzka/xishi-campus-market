# 网页测试与部署路线

版本 0.1.0-beta.1（测试版） · 日期 2026-10-19

## 1. 当前方向

按用户最新要求，夕拾作为网页项目开发，最终计划部署到网上；当前及后续迭代均为测试版。原桌面程序、EXE 构建和本地 / 联网设置已从当前代码移除。文档文件名保留以维持既有引用。

## 2. 浏览器测试

按 README 启动 FastAPI，然后在浏览器打开 http://127.0.0.1:8000。前端页面与 API 同源，不需要填写服务器地址或切换模式。自动化脚本 scripts/browser-test.cjs、scripts/search-browser-test.cjs 在隔离演示数据库执行，桌面窗口不再作为验收手段。

## 3. 网上部署

沿用 FastAPI + Vue + SQLite，部署步骤见 08 文档。服务器启动相同业务服务，由 HTTPS 代理提供统一网站地址，用户直接通过浏览器访问。目前公网未部署，容器和证书仍待目标服务器实测。

## 4. 历史记录及数据

旧桌面实现可从 Git 历史追溯，既有本机便携包和用户数据没有删除。历史桌面测试证据仅记录过去的尝试，不代表当前网页版本验证。旧桌面数据不会自动成为网站数据；需要迁移时应单独备份并验证数据库和上传图片。

## 5. 版本规则

当前标识为 0.1.0-beta.1，后续使用 beta 编号。代码修改以 Git 提交管理；确需 Release 时标为 Pre-release。未经用户明确确认，不视为正式版，不继续打包桌面软件。
