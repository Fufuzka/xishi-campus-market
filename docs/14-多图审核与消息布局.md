# 多图审核、消息整合与布局设置

网页测试版 0.2.0-beta.1 · 2026-10-19 · 非正式发布

## 1. 本次确认需求

用户确认商品发布图片与学生认证证明均需支持自由选择 1–3 张，管理员能点击打开图片。私信及交易约定整合，去掉无业务含义的“工作空间”文字；设置中提供几种网站布局。本次未引入 AI 审核或其他外部付费服务。

## 2. 商品图片

商品输入 `image_urls` 支持 1–3 个不同的合法图片地址；原 `image_url` 接口兼容旧调用并作为封面。上传支持多选、追加、移除，超过 3 张在上传前拒绝；服务端重复校验数量、地址及重复项。图片上传每张最多 5 MB，JPEG / PNG / WebP 解码后重编码为 JPEG，去除原始元数据。

products 增加 `image_urls` JSON 字段。旧商品无数组时从原封面构造单图数组，无需重新发布或删除旧图片。编辑时保留全量数组，首图作封面；审核及详情均展示缩略图。点击后打开独立图片查看器，支持前后切换、缩略图、左右方向键、Esc 关闭；Esc 仅关闭图片层，不关闭下方商品详情。原图按比例展示，不使用卡片裁切作为审核依据。

## 3. 学生认证证明与权限

新认证申请必须含 1–3 张证明。接口 `POST /api/verification-images` 上传后返回受保护 URL；文件位于 DATA/verification-images，未挂载到公开静态目录。GET /api/verification-images/{name} 校验 Cookie 会话，仅文件上传者及管理员可查看；游客 401，其他学生 404，响应 no-store。提交认证时校验每张图片确属当前用户，拒绝冒用他人文件、外链、重复或超量图片。

新增 verification_uploads(name, owner_id)，users 增加 verification_images JSON 字段。本人认证页与管理审核页可以放大所有图片。普通商品和求购接口不输出认证证明。旧已认证用户和旧无图申请保留，管理界面明确提示“旧申请未附证明图片”，不伪造证明；新提交及重新提交遵循新数量规则。认证仍是管理员人工核验，不代表学校官方学籍系统认证。

## 4. 消息与交易

侧栏仅保留“消息与交易”，删除重复的私信、交易约定入口。页面按会话展示对方、物品、最近消息及交易状态，支持全部、有交易、进行中、已完成过滤。

电脑为左侧会话列表、右侧聊天和交易卡；手机将会话列表收为可横向滚动区域，聊天和交易卡按单列排列。对话中可发起约定、确认面交时间地点、取消、分别确认完成；历史约定可展开回看。双方确认后商品售出，原订单状态规则与并发唯一约束保持有效。

新建订单在同一事务中创建或复用买卖双方商品会话，解决只下单而没先私聊时卖家无法进入对话的问题。POST /api/orders/{id}/conversation 仅订单双方可调用，用于将旧订单接入消息中心；即使商品软删除，订单和会话仍保留。会话匹配同时校验商品、买家及卖家，避免同商品不同买家的交易记录混入他人对话。历史同一会话的约定不会被新约定覆盖。

## 5. 三种布局

| 布局 | 内容结构 | 手机策略 |
|---|---|---|
| 林间集市 | 左侧导航、舒展商品卡片、绿色基调 | 横向导航、双列商品 |
| 轻简横栏 | 宽屏顶部导航、宽屏内容与较大图片 | 收敛为手机导航，减少横幅占用 |
| 清单浏览 | 侧栏导航、紧凑商品列表、便于对比 | 单列图文商品清单 |

顶部“外观设置”在电脑和手机均可见。设置使用示意缩略图，点击即时生效，当前选项有 aria-pressed。布局选择仅以白名单值保存到当前浏览器 localStorage，不包含账号、密码或认证资料；读取失败回退默认，不影响登录与业务。设置弹窗和图片预览互不影响业务表单。

删除“工作空间”标题及面包屑，只显示真实页面名称。保留夕拾品牌、测试版标识及原有登录清理规则。

## 6. 设计参考

统一消息页参考 [Material Design 的列表详情布局](https://m3.material.io/foundations/layout/canonical-examples/overview)，在宽屏并列展示选择列表与当前内容，窄屏重新组织区域。布局留白及卡片间距参考 [Atlassian 的间距体系](https://atlassian.design/foundations/spacing) 和 [网格原则](https://atlassian.design/foundations/grid)。使用这些结构原则，保留夕拾自有绿色配色、插画和校园业务，没有复制第三方页面、商标或素材。

## 7. 验收与证据

57 项接口测试通过，覆盖单图到三图、空数组／超量／重复／危险地址拒绝、证明图片所有权及读取隔离、自动订单会话及删除后历史保留，并回归原业务。浏览器累计 57 项：原业务 13、搜索 14、校园 14、登录清理 6、多图与布局 10；页面脚本错误为零。

本次专项包含三种布局在 1440、1000、390 宽度、重载持久化、多图追加和移除、管理员查看证明及商品图片、键盘操作、商品详情三图、仅下单自动建会话、聊天内操作交易、取消重约后的历史保留。原始证据为 evidence/web-api-tests.xml、experience-browser-results.json 及其他浏览器结果；截图 24–30 展示三种布局、证明／商品放大查看、统一消息页和手机消息页。

仍为本机测试版本，公网部署与导师评审待实际完成。测试图片为虚构验收素材，不是真实学生证件。上传后未用于申请的证明文件暂不自动清理，需按部署环境的资料保留政策制定清理流程。
