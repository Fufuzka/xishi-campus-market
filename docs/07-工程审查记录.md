# 工程审查记录

范围：当前 Web 实现的权限、隐私、数据完整性与运行边界。本记录为开发检查，不代替独立安全审计。

## 已实施的控制

| 领域 | 实现 |
|---|---|
| 身份与会话 | 带盐密码摘要、随机会话、服务端有效期、HttpOnly / SameSite Cookie；HTTPS 可启用 Secure |
| 所有权 | 商品修改、订单状态、消息与认证图片在服务端验证操作主体 |
| 角色 | 注册不接受管理员提权，管理员通过独立命令创建；停用后撤销会话 |
| 图片 | 验证实际内容、限制数量与大小、重编码、随机文件名，认证材料不公开托管 |
| 金额与状态 | 整数分、Decimal 输入、活动订单唯一索引、事务更新与双方确认 |
| 审核 | 认证和商品人工审核，商品编辑重新审核；举报处理与管理操作记录 |
| 恢复 | 安全答案仅存摘要，核验全部配置题目；恢复尝试限流，重置撤销全部会话 |
| 数据隔离 | 个人收藏、历史搜索、私信、订单及认证资料按所属主体过滤 |
| 输入 | Pydantic 校验、SQL 参数绑定、Vue 文本插值、请求来源检查 |

相关接口和边界由 tests/ 覆盖，浏览器操作证据位于 evidence/。具体执行日期、数量和范围见 [测试记录](06-测试计划与测试报告.md)。

## 已知限制

- 学生认证依赖人工审核，未接入学校身份服务。
- 安全问题的答案可能被猜测，不是强身份恢复方案；未接入邮箱、短信或其他恢复凭据。
- 恢复接口具备限流；登录、注册和其他业务仍需完善生产级滥用防护。
- SQLite 面向单实例；尚未完成负载和多节点验证。
- 上传后未关联记录的文件没有自动清理任务；数据保留策略需结合部署环境配置。
- 容器、证书签发、重启恢复和备份恢复需在目标环境验证。
- 消息采用轮询，尚无推送和已读回执。

## 变更复核

涉及角色、会话、恢复流程、私有图片或订单规则时，运行相关权限与失败路径测试。涉及布局和导航时，验证桌面、窄屏、键盘与真实点击；不以静态截图替代可操作检查。
